## $${\color{red}Website \ Audit \ Cheat \ Sheet}$$

from designer and developer point of view

---

### 🎯 STRATEGY

* [ ] Clear primary goal (sales / leads / traffic)
* [ ] Strong value proposition above the fold
* [ ] Clear CTA hierarchy (primary vs secondary)
* [ ] Each page has a single purpose
* [ ] Funnel logic is visible (TOFU → MOFU → BOFU)

---

### 🎨 UI DESIGN

* [ ] Clear visual hierarchy (headings, sections)
* [ ] Consistent spacing system (grid / 8pt)
* [ ] Typography readable (≥16px body, good line-height)
* [ ] Max 2–3 font families
* [ ] Consistent button styles
* [ ] Consistent color usage (design system)
* [ ] High contrast (WCAG compliant)
* [ ] Visual consistency across pages

---

### ⚙️ UX / USABILITY

* [ ] Navigation simple (≤7 items)
* [ ] Logical menu structure
* [ ] Important pages reachable in ≤3 clicks
* [ ] Clear CTA in each section
* [ ] No dead ends (every page leads somewhere)
* [ ] Forms are short and simple
* [ ] Inline validation in forms
* [ ] Helpful error messages

---

### 📱 MOBILE / RESPONSIVE

* [ ] Fully responsive layout
* [ ] No horizontal scrolling
* [ ] Tap targets ≥48px
* [ ] Mobile-friendly navigation
* [ ] Text readable without zoom
* [ ] Images scale correctly

---

### 🚀 PERFORMANCE

* [ ] Page loads < 3 seconds
* [ ] LCP < 2.5s
* [ ] CLS < 0.1
* [ ] Images optimized (WebP/AVIF)
* [ ] Lazy loading enabled
* [ ] CSS/JS minified
* [ ] Unused CSS/JS removed
* [ ] Fonts optimized (no blocking)

---

### 💻 DEVELOPMENT

* [ ] Semantic HTML used
* [ ] No console errors
* [ ] Clean, modular code
* [ ] No unnecessary inline styles
* [ ] Accessibility attributes implemented
* [ ] Cross-browser compatibility tested

---

### 🔐 SECURITY

* [ ] HTTPS enabled
* [ ] Forms validated & sanitized
* [ ] Protection against XSS / CSRF
* [ ] CMS/plugins up to date
* [ ] Backup system configured

---

### 🔍 SEO

* [ ] Unique meta titles & descriptions
* [ ] Proper heading structure (H1–H6)
* [ ] Sitemap.xml exists
* [ ] Robots.txt configured
* [ ] Canonical tags set
* [ ] Internal linking implemented
* [ ] Images have alt text
* [ ] No duplicate content

---

### ♿ ACCESSIBILITY

* [ ] Keyboard navigation works
* [ ] Visible focus states
* [ ] Alt text for all images
* [ ] Labels for inputs
* [ ] Sufficient color contrast
* [ ] No autoplay with sound

---

### 📊 ANALYTICS

* [ ] GA4 installed
* [ ] Events tracked (clicks, forms)
* [ ] Conversion goals configured
* [ ] No duplicate tracking
* [ ] Cookie consent implemented

---

### ✍️ CONTENT

* [ ] Clear, benefit-driven headlines
* [ ] No placeholder text
* [ ] Grammar & consistency checked
* [ ] CTAs are specific (“Get Quote”, not “Submit”)
* [ ] Content matches user intent

---

### 🧩 CMS (WordPress / etc.)

* [ ] Theme optimized (no bloat)
* [ ] Plugins minimized
* [ ] SEO plugin configured
* [ ] Security plugin active
* [ ] Regular backups enabled

---

#### 🧪 QUICK AUDIT FLOW

* [ ] First impression (5 min)
* [ ] Key pages review (10 min)
* [ ] Mobile check (10 min)
* [ ] Performance + SEO scan (10 min)
* [ ] Final notes + fixes (15 min)
