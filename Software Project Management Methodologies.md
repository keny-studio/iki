## $${\color{red}Software \ Project \ Management \ Methodologies}$$
---

### 🔹 1. Waterfall (Linear)

**Concept:** Sequential phases, no overlap
**Flow:** Requirements → Design → Development → Testing → Deployment → Maintenance

**Best for:**

* Fixed scope projects
* Regulated industries (finance, healthcare)

**Pros:**

* Clear structure & documentation
* Easy to manage timelines

**Cons:**

* Inflexible to changes
* Late testing feedback

---

### 🔹 2. Agile (Iterative)

**Concept:** Iterative, incremental delivery with continuous feedback

**Core values (Agile Manifesto):**

* Individuals & interactions > processes
* Working software > documentation
* Customer collaboration > contracts
* Responding to change > following plan

**Best for:**

* Dynamic, evolving requirements
* Product development

**Pros:**

* Flexible & adaptive
* Frequent releases

**Cons:**

* Less predictability
* Requires strong team collaboration

---

### 🔹 3. Scrum (Agile Framework)

**Concept:** Agile framework using fixed-length iterations (Sprints)

**Key Roles:**

* Product Owner
* Scrum Master
* Development Team

**Artifacts:**

* Product Backlog
* Sprint Backlog
* Increment

**Events:**

* Sprint Planning
* Daily Standup
* Sprint Review
* Retrospective

**Sprint length:** 1–4 weeks

**Best for:**

* Small to medium teams
* Continuous product delivery

---

### 🔹 4. Kanban (Flow-Based)

**Concept:** Visual workflow with continuous delivery

**Core principles:**

* Visualize work (board)
* Limit WIP (Work in Progress)
* Manage flow
* Continuous improvement

**Typical Columns:**
To Do → In Progress → Review → Done

**Best for:**

* Support/maintenance teams
* Continuous delivery environments

**Pros:**

* Simple & flexible
* No fixed iterations

**Cons:**

* Less structure than Scrum
* Harder to forecast deadlines

---

### 🔹 5. Lean Software Development

**Concept:** Maximize value, minimize waste

**7 Principles:**

1. Eliminate waste
2. Build quality in
3. Create knowledge
4. Defer commitment
5. Deliver fast
6. Respect people
7. Optimize the whole

**Best for:**

* Efficiency-focused teams
* Startups

---

### 🔹 6. Extreme Programming (XP)


**Concept:** Agile methodology focused on engineering practices

**Core Practices:**

* Pair Programming
* Test-Driven Development (TDD)
* Continuous Integration
* Refactoring
* Small releases

**Best for:**

* High-quality code environments
* Fast-changing requirements

---

### 🔹 7. DevOps (Culture + Practices)


**Concept:** Integration of Development + Operations

**Key Elements:**

* CI/CD (Continuous Integration / Delivery)
* Automation
* Monitoring
* Infrastructure as Code

**Lifecycle:**
Plan → Code → Build → Test → Release → Deploy → Operate → Monitor

**Best for:**

* Scalable systems
* Cloud-native apps

---

### 🔹 8. SAFe (Scaled Agile Framework)


**Concept:** Scaling Agile across large organizations

**Levels:**

* Team
* Program (Agile Release Train)
* Portfolio

**Best for:**

* Enterprises with many teams

---

### ⚖️ Quick Comparison

| Methodology | Structure | Flexibility | Delivery Style    | Best For     |
| ----------- | --------- | ----------- | ----------------- | ------------ |
| Waterfall   | High      | Low         | One-time          | Fixed scope  |
| Agile       | Medium    | High        | Iterative         | Product dev  |
| Scrum       | High      | High        | Sprint-based      | Teams        |
| Kanban      | Low       | High        | Continuous        | Support      |
| Lean        | Medium    | High        | Optimized flow    | Efficiency   |
| XP          | Medium    | High        | Frequent releases | Code quality |
| DevOps      | Medium    | High        | Continuous        | Deployment   |
| SAFe        | High      | Medium      | Scaled Agile      | Enterprise   |

---

### 🧩 When to Use What (Rule of Thumb)

* **Unclear requirements?** → Agile / Scrum
* **Continuous work stream?** → Kanban
* **Enterprise scale?** → SAFe
* **Strict deadlines & specs?** → Waterfall
* **Code quality critical?** → XP
* **Automation & deployment focus?** → DevOps
